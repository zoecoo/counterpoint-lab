# Counterpoint Lab

無建置步驟的靜態音樂實驗室，全部功能在單一 `index.html` 內。直接開啟檔案，或透過 GitHub Pages 使用。

Steve Reich 啟發的生成式對位：選擇主音與十一種調式（五聲、教會調式、和聲／旋律小調），調整 BPM、聲部數（2–8）、固定聲部位移與累積速度。「生成新旋律」建立新的節奏素材；更換主音或調式時立即重新映射音高、保留節奏。勾選「逐步加入音符」時，每經過設定的循環數增加一音，完成後重新開始。

聲部矩陣以色塊顯示各聲部的發音位置，播放時標示目前拍點。此模型是固定聲部位移的卡農，並非連續的 Phasing。

每個聲部的標籤下方有音域條：以全體聲部音高範圍為底，彩色段落標出該聲部的位置與寬度（懸停顯示確切音名），譜面聲部名稱分兩行顯示：名稱在上、音域小字在下，避免撐寬左邊距。音符帶有長度並以連續長條顯示於矩陣。每格點一下切換有聲／休止：點長條任一格變回休止（點中段截短該音）；點緊接在長條後的空格延長該音（最長四格），其他空格新增音符。每列可靜音或移除（播放中也可操作，原地更新不中斷），矩陣下方的「新增聲部」按鈕可加入空白聲部直接編輯。調整聲部數或位移會重建基礎聲部並保留衍生與自訂聲部。力度滑桿同步影響音訊音量與 MIDI velocity。「聲部進場間隔」讓聲部在播放時依序進場（未進場的列顯示為半透明），設為「同時」則全部一起發聲；與逐步加入音符並用時，循環長度取兩者完成時間的較大值。

譜面面板由 abcjs 引擎（vendored 於 `abcjs-basic-min.js`，無 CDN 依賴）繪製標準記譜：同拍音符自動連杠，每個聲部自動選擇加線最少的譜號（高音、低音或帶 8 的八度譜號，記譜移八度），升降記號依小節內規則顯示，音符顏色對應矩陣聲部。記譜隨建構階段更新，只顯示目前已加入的音符；編輯後約 0.25 秒重繪。

Resultant Pattern Composer 先計算每格的顯著度（同時起音的聲部數與拍點權重），再依策略擷取重音骨架——高音線取旋律局部高點、低音線取低音支點、連貫線與交錯線取最顯著的重音點——組成有節奏的隱藏旋律（音長依間距延伸，而非逐格取音）。去除重複後依旋律連貫、重音與密度評分排序（啟發式，非確定的聽覺預測）。可逐一試聽、手動加入或自動選取最高分者；加入後可繼續分析衍生，上限 16 聲部。

播放使用 AudioContext 時鐘前瞻排程（120ms lookahead），拍點高亮與譜面階段重繪都對準實際發聲時刻。互動播放需由使用者點擊啟動 AudioContext；頁面進入背景會自動停止。

MIDI 匯出為 Standard MIDI File format 1、480 PPQ，含速度軌與各聲部軌，依目前的累積設定輸出完整建構過程；音長會反映在 note 時值，重疊時自動截斷至下一個音的起點。

GitHub Actions workflow 將 main 部署至 GitHub Pages，repository Pages source 應設定為 GitHub Actions。
