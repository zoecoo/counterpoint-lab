# Counterpoint Lab

無建置步驟的靜態音樂實驗室，全部功能在單一 `index.html` 內。直接開啟檔案，或透過 GitHub Pages 使用。寬螢幕採雙欄版面：操作面板固定在右側（捲動時跟隨），矩陣、譜面與 Composer 在左側；窄螢幕為單欄。

Steve Reich 啟發的生成式對位：選擇主音與十二種調式（五聲、教會調式、和聲／旋律小調，以及「自由（半音階）」——把調式當成可選的座標系，音高面板開放全部十二個音名，自訂任意音高集合），調整 BPM、聲部數（2–16）、固定聲部位移與累積速度。「生成新旋律」建立新的節奏素材；更換主音或調式時立即重新映射音高、保留節奏。勾選「逐步加入音符」時，每經過設定的循環數增加一音，完成後重新開始。

聲部矩陣以色塊顯示各聲部的發音位置，播放時標示目前拍點。矩陣最上方的「母題」列是所有基礎聲部共用的素材，可直接編輯（搭配「輸入音高」選單），編輯後基礎聲部立即重建、衍生與自訂聲部保留——整條旋律因此完全可自訂。母題列最右側的小 ▶ 按鈕可單獨試聽母題一輪（再按一次停止）。此模型是固定聲部位移的卡農，並非連續的 Phasing。

每個聲部的標籤下方有音域條：以全體聲部音高範圍為底，彩色段落標出該聲部的位置與寬度（懸停顯示確切音名），譜面聲部名稱分兩行顯示：名稱在上、音域小字在下，避免撐寬左邊距。音符帶有長度並以連續長條顯示於矩陣；建構模式下尚未輪到的音符以極淡的幽靈長條預示，點擊即立即加入。每格點一下切換有聲／休止：點長條任一格變回休止（點中段截短該音）；點緊接在長條後的空格延長該音（最長四格），其他空格新增音符。每列可靜音或移除（播放中也可操作，原地更新不中斷），矩陣下方有兩顆新增按鈕：「新增素材聲部」以同一母題接續卡農位移產生下一個聲部（變化開啟時套用互補子集）；「新增自訂聲部」加入空白聲部直接編輯；點母題列的任何格子會開啟音高面板：音名（依調式列出，左右兩欄）× 八度（2–6）× 音長（十六分到四分）× 升降（♭♮♯），點選立即生效並重建基礎聲部，亦可設為休止；空格首次點選即新增音。點在長音的「延音格」上，編輯只從該格切開生效：前段保留原本的音高與起點，該格起成為新的音（面板預選原音高，方便只改一拍）；選「休止」則把長音截短到該格之前，不會整顆音消失。升降以「音級＋變化音」的形式保存，換調式時維持同音級的升降關係。頁首顯示 build 編號，可用於確認快取是否更新。聲部矩陣的點擊是素材開／關：點長條休止（中後段截短）、點空格把素材的音找回來；素材沒有音的空格同樣開啟面板新增自訂音。調整聲部數或位移會重建基礎聲部並保留衍生與自訂聲部。力度滑桿同步影響音訊音量與 MIDI velocity。「聲部進場間隔」讓聲部在播放時依序進場（未進場的列顯示為半透明），設為「同時」則全部一起發聲；與逐步加入音符並用時，循環長度取兩者完成時間的較大值。

譜面面板由 abcjs 引擎（vendored 於 `abcjs-basic-min.js`，無 CDN 依賴）繪製標準記譜：同拍音符自動連杠，每個聲部自動選擇加線最少的譜號（高音、低音或帶 8 的八度譜號，記譜移八度），升降記號依小節內規則顯示，跨半小節的音依記譜慣例拆分並以連結線相連（小節內的切分音保持原時值，符合十六分格律音樂的寫法），音符顏色對應矩陣聲部。記譜隨建構階段更新，只顯示目前已加入的音符；編輯後約 0.25 秒重繪。

「變化」面板提供可勾選的總開關（預設關閉，維持嚴格卡農）：啟用後，生成時可使用互補子集（各聲部演奏素材的不同隨機片段，保證互補涵蓋完整母題）；播放中可依機率每小節微變（找回被遮的音、拿掉或挪動單音），並可每 N 小節整體重配子集（如翻到新段落）。變化即時反映在矩陣與譜面；手動編輯會被重配與重建覆蓋。

Resultant Pattern Composer 模擬聽覺流分離（auditory streaming）：人耳把「音高相近、時間相鄰」的音連成線，寧可跳過時點也不接受大跳（Bregman 1990）。分析流程依感知文獻設計：(1) 織體折疊到單一 16 格循環；(2) 標記重疊音——兩個以上聲部同時發同一音高時振幅近乎加倍，知覺上是重音，很多浮現旋律就是被加倍的音連成的線（選音時重疊音加權優先，並另列「重疊重音線」候選）；(3) 以 3 半音為間隔在全體音域內滑動音高帶，每帶追蹤一條路徑——只接受焦點 ± 容忍度內的音，容忍度隨 BPM 縮小（van Noorden 1975：速度越快，耳朵容忍的音程越小；60 BPM 以下 ±10 半音，150 BPM 以上 ±5），焦點以指數移動平均跟隨；(4) 依成本函數評分排序：音程平滑 35%、節奏規律（IOI 變異）20%、重疊音加成 20%、循環內週期性 15%、密度 10%。音長延伸至下一個音（上限四分音符）。去重後輸出前六條；浮現旋律本質多義（Reich 在 Violin Phase 譜上自己就寫了多種聽法），分數是啟發式排序，請以耳朵驗證。可逐一試聽、手動加入或自動選取最高分者；加入後可繼續分析衍生，上限 16 聲部。

播放使用 AudioContext 時鐘前瞻排程（120ms lookahead），拍點高亮與譜面階段重繪都對準實際發聲時刻。不同聲部重疊的同音會合併成一次起音（延音取較長者、較長的音無縫接續），避免同音疊加聽成重複起音。互動播放需由使用者點擊啟動 AudioContext；頁面進入背景會自動停止。

MIDI 匯出為 Standard MIDI File format 1、480 PPQ，含速度軌與各聲部軌，依目前的累積設定輸出完整建構過程；音長會反映在 note 時值，重疊時自動截斷至下一個音的起點。

GitHub Actions workflow 將 main 部署至 GitHub Pages，repository Pages source 應設定為 GitHub Actions。
